## 3. 사용자 이용 흐름 *

### 심사위원

```text
공개 URL
  → 데모 시나리오 선택
  → 가상 문자 분석
  → 연관 전화·설문
  → 위험 근거·모의 보호자 알림
  → S0~S4 대응 체크리스트
```

### 보호 대상자

```text
6자리 코드
  → 연결·동의
  → 권한 설정
  → 문자/전화 감지 또는 직접 입력
  → 로컬 경고
  → 최종 결과·확인 요청
```

### 보호자

```text
로그인
  → 담당 대상자 대시보드
  → CRITICAL 웹 푸시
  → 사건 상세
  → 전화
  → 체크리스트·상태 갱신
```

## 4. AI 및 데이터 처리 방식 *

- 위험 수준: 결정적 규칙, URL·번호 평판, 문자–전화 연관, 행동 신호
- 생성형 AI: 확정된 근거의 쉬운 문장 변환과 사건 요약만 수행
- 금지: LLM이 위험 수준·점수·알림 여부 변경
- 기본 입력: 원문 대신 추출된 특징과 최소 메타데이터
- 문자 원문 분석: 별도 동의 요청에서만 메모리 처리 후 폐기
- P0 문자 원문 보호자 공유 없음. P1에서는 사건·연결별 승인 후 암호화 grant로 15분 또는 첫 조회까지
- 데이터 출처: `data-sources.md`의 검증·승인된 source만 사용
- 실패: 템플릿 설명과 `UNKNOWN`/`FINALIZED_PARTIAL`

현재 결정적 RiskEngine 정책은 `v1.1.0`, 정책 버전은 `2026-07-28.1`, 입력 스키마는
`1`입니다. LLM adapter에는 위험 수준·범주·신호 근거·행동 ID·사건 단계만 전달하며 문자
원문·전화번호·URL은 전달하지 않습니다. OpenAI Responses API는 선택 설정이고 `store=false`,
1.5초 timeout, strict JSON schema를 적용합니다. 기본값과 모든 오류 경로는 검수된 template
설명입니다. KISA·Safe Browsing의 실제 데이터 버전과 OpenAI 모델의 품질·latency 결과는
승인·staging 검증 후 채웁니다.

## 5. MVP 검증 방법 *

| 항목 | 제출 시 입력 |
|---|---|
| 공개 URL | `TO_BE_FILLED` |
| 보호자 테스트 계정 | `TO_BE_FILLED` |
| APK 다운로드·checksum | `TO_BE_FILLED` |
| 권장 브라우저 | Chromium desktop 1440×1000·mobile 390×844에서 `/demo` 확인 |
| 주 Android 기기 | API 29·36 emulator 통과, Samsung Android 14+ 실기기 확정 대기 |
| 샘플 입력 | `scenarios.md`의 공개 fixture |
| 예상 결과 | 시나리오별 risk level·signals·incident stage |
| 제한사항 | 자동 감지 지원 조합과 외부 API 조건 |
| 테스트 결과 | API 57건·RiskEngine 23건·Web 11건·Android 22건·PostgreSQL 통합 흐름 1건, TypeScript build·browser QA 통과 |

현재 검증 제한:

- Firebase 실제 프로젝트 설정이 없어 Google 로그인 이후 대시보드와 실제 Web Push는 staging
  검증 전입니다.
- Android 수동 경로는 API 36 emulator에서 확인했으며 6자리 연결→서버 최종 결과의 단일
  실기기 E2E는 Firebase 테스트 계정 준비 후 수행합니다.
- 보호자 사건 카드의 즉시 전화 CTA는 대상자 연락처 저장·공유 정책 확정 후 구현합니다.
- URL 외부 평판은 승인된 공급자 설정 전까지 `FINALIZED_PARTIAL` fallback으로 동작합니다.
- OpenAI 설명은 실제 key·모델을 설정하지 않은 상태이며 현재는 동일 API 계약의 template
  fallback을 사용합니다.

최종 제출 전:

- 미구현·불안정 기능 삭제
- `VERIFIED` 근거 없는 기능 삭제
- 실제 URL·계정·브라우저로 새 기기에서 재현
- 데모 합성 데이터와 실제 보호자 흐름을 구분
- 목표 수치가 아니라 실측 수치만 기재
